## About

**CursorVault** is a Windows application developed by **GLX** to make managing Windows cursors simple and centralized.

It lets you import `.cur` and `.ani` files, organize complete cursor packs, quickly apply a new cursor theme, and manage schemes already installed in Windows.

The goal is simple: provide a modern and convenient alternative to manually configuring cursors through the Windows Control Panel.

## Features

### 📚 Cursor library

- Local pack library
- Favorites
- Search by name, creator and description
- Filters for complete, incomplete, animated, static and favorite packs
- Sort by favorites, name, creator, completeness or date added
- Light / Dark variant detection
- Random pack selection
- Original creator display

### 📥 Import

- Folder import
- ZIP archive import
- `.cur` file import
- `.ani` file import
- Drag and drop directly into CursorVault
- Automatic local installation
- Duplicate detection
- Export a pack as ZIP

### 🛠️ Creation and analysis

- Built-in pack creator
- Pack renaming
- Original creator credit preservation
- Analysis of available Windows cursor roles
- Missing file detection
- Invalid file detection
- Duplicate detection
- CUR and ANI validation
- Broken reference repair
- `install.inf` generation

### 🖱️ Windows integration

- Automatic application of complete packs
- Windows cursor role management
- Display of schemes already installed in Windows
- Active scheme detection
- Direct application of Windows schemes
- Access to Windows pointer settings
- Access to the system cursor folder
- Optional synchronization with the Windows light / dark theme

### ⭐ Automation

- Automatic pack rotation
- Rotation at startup
- Hourly rotation
- Daily rotation
- Favorites-only rotation
- Start with Windows
- Minimize to the notification area

### 💾 Backup

- Backup of the current Windows cursor scheme
- Full `.cvb` backup
- Settings restoration
- Pack restoration
- Favorites restoration
- Portable mode
- Storage management
- Cache cleanup

### 🎨 Customization

- Dark theme
- Light theme
- Customizable color
- Font selection from fonts installed in Windows
- Compact, normal or large interface size
- Settings reset

### 🌍 Languages

CursorVault can automatically use the Windows display language.

Available languages:

- Français
- English
- Español
- Deutsch
- Italiano

A language can also be selected manually in Settings.

### 🔍 Diagnostics

- Built-in Diagnostics page
- System information
- CursorVault configuration information
- Copy diagnostics to the clipboard
- Storage information
- Cache cleanup

## Installation

1. Open the [latest CursorVault release](https://github.com/GaLeX-Le-Penguin/CursorVault/releases/latest)
2. Download **`CursorVault.zip`**
3. Extract the archive completely
4. Launch **`CursorVault.exe`**

```text
CursorVault/
├── CursorVault.exe
└── CursorVault_Data/
```

No separate .NET installation is required with the official build.

## User data

CursorVault stores the data required for operation locally, including imported packs, favorites, settings, backups and cache files.

A **portable mode** is also available to keep data alongside the application.

---

## Supported formats

- `.cur`
- `.ani`

Packs are analyzed before being applied to detect missing or invalid files.
