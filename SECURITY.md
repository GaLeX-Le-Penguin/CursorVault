# Security Policy

## Supported Versions

Security fixes are provided for the latest release of CursorVault.

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |
| Older versions | No |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting feature when available.

When reporting a vulnerability, include:

- A clear description of the issue
- Steps to reproduce it
- The affected CursorVault version
- The affected Windows version
- The potential security impact
- Any relevant screenshots, logs, or proof of concept

Please allow reasonable time for investigation and remediation before publicly disclosing the vulnerability.
